# 股票市场监控系统

一个实时监控股票市场的系统，可以自动扫描市场并识别交易量异常的股票。

## 功能特点

- 每10分钟自动扫描一次市场
- 智能识别交易量异常的股票
- 实时显示市场状态（开放/关闭）
- 交互式数据可视化仪表板
- 自动跳过非交易时段

## 安装步骤

1. 克隆仓库：
```bash
git clone <仓库地址>
cd stock_monitor
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

## 使用方法

1. 启动监控程序：
```bash
python monitor.py
```

2. 启动仪表板（在新的终端窗口中）：
```bash
python dashboard.py
```

3. 访问仪表板：
- 打开浏览器访问 `http://localhost:8050`
- 仪表板会自动每30秒更新一次数据

## 仪表板功能

### 市场状态
- 显示当前市场是否开放
- 显示最后更新时间
- 显示下一个市场开放日期

### 数据过滤
- 日期范围选择器（默认显示最近7天）
- 交易量比率滑块（1-5倍）

### 股票列表
- 显示所有感兴趣的股票
- 包含以下信息：
  - 股票代码
  - 公司名称
  - 当前价格
  - 交易量
  - 市值
  - 交易量比率

### 交易量分析图表
- 显示交易量比率随时间的变化
- 按股票代码着色
- 支持交互式缩放和悬停

## 配置说明

可以通过修改 `config.py` 文件来调整系统参数：

```python
# 市场扫描设置
SCAN_SETTINGS = {
    'scan_time': '09:30',  # 每日扫描时间
    'volume_analysis_period': '3mo',  # 交易量分析周期
    'min_market_cap': 1e9,  # 最小市值要求
    'min_price': 5.0,  # 最小股价要求
}

# 交易量分析设置
VOLUME_SETTINGS = {
    'peak_threshold': 2.0,  # 交易量峰值阈值
    'min_volume': 100000,  # 最小交易量要求
}
```

## 注意事项

1. 系统只在市场开放时段进行扫描
2. 确保网络连接稳定
3. 数据仅供参考，不构成投资建议
4. 建议在交易时段运行系统

## 日志查看

系统运行日志保存在 `stock_monitor.log` 文件中，可以通过以下命令查看：
```bash
tail -f stock_monitor.log
```

## 数据库

所有扫描结果都保存在 SQLite 数据库中（`stock_monitor.db`），包括：
- 市场状态记录
- 股票扫描结果
- 交易量分析数据

## 常见问题

1. **仪表板无法访问**
   - 确保仪表板程序正在运行
   - 检查端口 8050 是否被占用

2. **没有扫描结果**
   - 检查市场是否开放
   - 确认网络连接正常
   - 查看日志文件了解详细信息

3. **数据更新延迟**
   - 检查网络连接
   - 确认监控程序正常运行
   - 查看日志文件排查问题
